# Политика конфиденциальности

**Приложение:** Таблица умножения (Multiplication Master)

**Разработчик:** Maria Katushonak Apps

**Дата вступления в силу:** 22 октября 2026 года

### 1. Общая информация

Приложение «Таблица умножения» предназначено для изучения и тренировки таблицы умножения.

Мы уважаем конфиденциальность пользователей, в том числе детей, и стремимся обеспечить безопасное использование приложения.

### 2. Сбор персональных данных

Приложение не собирает и не передаёт персональные данные пользователей.

Для использования приложения не требуется регистрация, создание учётной записи или предоставление личной информации.

### 3. Хранение данных

Результаты тренировок, достижения и учебный прогресс сохраняются локально на устройстве пользователя.

Эти данные используются исключительно для работы образовательных функций приложения и не передаются разработчику или третьим лицам.

### 4. Доступ к интернету и реклама

Приложение работает без подключения к интернету.

Приложение не содержит рекламы, не использует рекламные идентификаторы и не применяет сторонние аналитические сервисы.

### 5. Конфиденциальность детей

Приложение предназначено для образовательных целей и может использоваться детьми.

Приложение не запрашивает персональные данные детей, не предоставляет возможности общения с другими пользователями и не содержит встроенных покупок.

### 6. Удаление данных

Пользователь может удалить локально сохранённые данные приложения, очистив его хранилище в настройках Android или удалив приложение с устройства.

### 7. Изменения политики

При изменении функциональности приложения настоящая политика конфиденциальности может быть обновлена.
